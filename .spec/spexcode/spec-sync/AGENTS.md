# Spec 同步规范树

本目录保存持续双向同步的产品契约，不保存运行记录。当前待实现节点保持 `status: pending`；只有对应实现和当前版本证据存在后才能更新状态。

- 顶层 `spec.md` 保存九项需求、阶段及验收映射；子节点拥有各自规则，引用上层规则，不复制业务政策。
- `sync-contract-schema/spec.md` 是 sync-v1 固定 Markdown 语法；解析图、状态图、覆盖率与证据是派生产物。
- 每个叶节点最多治理一个现存代码文件；尚无实现时不添加虚构 `code:` 锚点。
- 修改实现时同步对应节点及针对性测试；运行命令下沉到实现目录。
