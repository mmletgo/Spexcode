# 冻结候选的真实符号锚点验证

## raw source

同步完成前，契约引用的代码符号必须存在于实际验证的候选版本，不能被宿主工作区的另一份源码或候选提供的解析器冒充。

## expanded spec

本节点承担 [[sync-verification]] 的 V1 符号检查，复用现有 [[code-anchor]] 语言注册表、不可变内容解析缓存和唯一符号判定。输入只有契约图与冻结文件文本；在第一次异步解析前固定查询与文本，不读取当前项目文件、不加载候选依赖、不执行候选代码。

检查 code、带符号的 related 和业务项的 code 来源；related 仍不计实现覆盖。每个声明保留节点、路径、来源位置和符号证据。缺失文件、未知语言、解析器不可用、语法错误、符号消失或重名都阻止该锚点通过，不使用正则回退。类型符号保留既有警告，不伪称业务行为已经验证。

文件存在、其他契约结构、业务语义和运行行为继续由其所属门禁处理；此检查通过不代表已经同步。
