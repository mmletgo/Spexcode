# 契约纯核心的针对性回归边界

## raw source

## expanded spec

验收依据为 [[sync-contract-schema]] 及其技术叶。针对性测试使用明确来源的导出夹具，覆盖 raw 草稿、Markdown 围栏与转义、语法错误、身份与引用、依赖循环、对象状态事件处置、状态可达性、无状态流程和依赖范围投影。

真实文件声明、注释和字符串伪标题、测试 API 导入别名、跨节点验收与实现分离、非业务 VERIFY 覆盖及无 Git 仓库纯入口均有正反例。夹具政策只用于这些场景，不形成用户项目默认业务规则；局部测试通过不代替自然语言细化、实际产品运行或全量同步验收。

测试命令由实现目录 `packages/spec-core/src/contracts/AGENTS.md` 维护，按构建后的公开入口执行；本节点不另维护命令或运行结果。
