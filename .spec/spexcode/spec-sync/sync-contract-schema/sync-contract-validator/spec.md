# 契约声明完整性与真实文件绑定检查

## raw source

结构错误和未验证绑定必须可见；完整声明不能被误解为业务语义正确或实际验收通过。

## expanded spec

业务正确性约束属于 [[sync-contract-schema]]。`validateContractGraph` 的草稿模式检查已有结构，默认完成模式另检查需求、流程、规则、验收映射，以及对象初始状态、事件处置、可达性、非终态出口和流程结束。推导来源与依赖循环阻断，合法状态及导航循环保留。

治理文件、代码来源与测试绑定只用调用方传入的文件文本判断，核心不读取磁盘。未提供文件上下文保留绑定未验证提示；已提供时检查文件存在及实际静态测试标题中的稳定用例 ID，合法测试 API 导入别名有效，注释或字符串示例不计声明。间接 VERIFY 入口的用例选择保留待运行确认提示。

未决 GAP 报告其依赖范围；自然语言条件、输入域、竞争顺序和副作用需要独立语义审查及具体测试。诊断没有运行通过或已交付结论。
