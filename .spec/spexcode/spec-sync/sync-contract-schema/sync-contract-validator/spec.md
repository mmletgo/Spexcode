# 契约声明完整性与真实文件绑定检查

## raw source

结构错误和未验证绑定必须可见；完整声明不能被误解为业务语义正确或实际验收通过。

## expanded spec

业务正确性约束属于 [[sync-contract-schema]]。`validateContractGraph` 的草稿模式检查已有结构，默认完成模式另检查需求、流程、规则、验收映射，以及对象初始状态、事件处置、可达性、非终态出口和流程结束。STEP 显式 depends-on/source 引用 EVENT 时，完成模式要求 next、depends-on 或直接 TR source 中有匹配事件的处置，否则报告 `step-event-disposition-missing` 并关联步骤及 EVENT；草稿保留待细化。该检查不推断正文状态域或补全全部同事件 TR，处置集合完整性由独立语义审查承担。推导来源与依赖循环阻断，合法状态及导航循环保留。

治理文件、代码来源与测试绑定只用调用方传入的文件文本判断，核心不读取磁盘。未提供文件上下文保留绑定未验证提示；已提供时检查文件存在及实际静态测试标题中的稳定用例 ID，合法测试 API 导入别名有效，注释或字符串示例不计声明。间接 VERIFY 入口的用例选择保留待运行确认提示。

测试声明统一解析 JS、TS 和 JSX 语法，按词法作用域识别 test/it 或可信测试 API 的导入别名及 only/skip/todo 调用。标题允许直接字符串，以及封闭 const 字面量、数组、对象组成的模板、简单索引和 const for-of 标识符绑定；整段标题须可静态归因。未用于测试的常量、同名局部变量或参数、未知函数结果、动态插值与索引、可见写入或成员调用（含 optional 调用）涉及的数据不能证明稳定用例声明；失效沿可见赋值和解构的来源传播。非调用表达式中的条件、序列、展开及其他包装不求值，统一沿真实 AST 子节点收集可能来源；对象属性只收集值与 computed key，类型标注不计运行来源，这些可见来源无法精确区分时保守失效。调用、构造和函数体是来源推断边界，不推断它们的返回别名或副作用；此声明检查不承诺整段 JS 的运行稳定性。无法解析的源文本或不支持的标题表达式保持未声明；不执行候选代码，不推断运行分支或断言含义。同次验证复用同一文件的标题提取结果，不保存跨次状态。

未决 GAP 报告其依赖范围；自然语言条件、输入域、竞争顺序和副作用需要独立语义审查及具体测试。诊断没有运行通过或已交付结论。

已识别测试 API 的 `each` 注册调用不作为测试 API 绑定的数据修改，不影响同文件其他直接测试标题的声明检查；这里不展开或解析 `each` 的参数化标题。普通数据绑定上的成员调用失效检查保持生效。
