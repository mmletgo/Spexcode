# 契约核心类型与派生结果边界

## raw source

调用方需要在同一类型边界中传递原始契约、稳定身份和派生结果，避免把声明覆盖当成执行证据。

## expanded spec

语法、业务项含义和规则权威属于 [[sync-contract-schema]]。本节点只治理对应 TypeScript 类型：业务项与 VERIFY 区分；每项携带节点、Spec 路径和行位置；业务项保留来源及推导依赖。契约保存原意、详细正文、治理及上下文映射。

图以稳定 ID 索引条目、归属、依赖和消费者；验证上下文由调用方提供完成模式、真实文件和可用节点身份。覆盖、状态事件矩阵、GAP 范围及影响结果是派生类型，覆盖状态不包含运行通过。类型定义不读取文件、不运行命令，也不登记交付结果。
