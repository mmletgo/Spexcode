# 跨冻结分区证据的完整 Git 差量

## raw source

在干净主分支重新发起 initial 之后，旧分区证据仅在当前独审确认适用于新冻结输入时才可复用。共享依赖、测试、契约或配置即使从未列在旧分区读集，也可能影响当前独审。

## expanded spec

可信层从两次真实操作取得原始冻结输入。两端须属于同一存续的 canonical 仓库与工作树，绑定精确的提交和 tree；原提交须为当前提交的严格祖先。分支倒退、无关历史、浅仓库、替代祖先和缺失证据均不得形成复用证据。仅根据冻结对象比较，当前分支在结算后继续前进不改变已冻结差量。

版本化差量包含两端冻结输入 ID、提交、树、每个实际变化路径的前后 mode/OID 或缺席，以及完整 Git 内容补丁。重命名表示为删除和新增。路径来自 NUL 分隔的 Git 记录，不按行切割。差量与路径不按旧分区文件、读集或命中范围裁剪，证据摘要覆盖完整正文。差量无法完整表示、超出有界证据容量或触及宿主私有路径时，当前分区沿完整现行流程执行。

这份差量只供当前独审逐项判断旧证据能否用于当前分区。复用要绑定当前审核、双方原件、当前分区权责和完整差量摘要。任何变化无法审查或影响无法确定时，继续执行该分区的原有授权步骤。正式验证和采纳遵循 [[sync-coordinator]]。
