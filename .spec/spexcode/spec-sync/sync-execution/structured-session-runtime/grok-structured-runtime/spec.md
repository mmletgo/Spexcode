# Grok Build 原生工作树执行

## raw source

Claude Code 或 ZCode 限流时，用户可以显式选择本机已配置的 Grok Build 接续。Grok Build 在 SpexCode 创建的隔离工作树中完成原任务，沿用正式独审、验收和交付。

## expanded spec

明确的 `grok:<模型或别名>` 仅进入 [[structured-session-runtime]] 的原生 worktree 路由。`grok:default` 沿用本机配置。每轮记录实际 CLI 版本和模型。选择、输入、预算、独审身份与正式重试规则沿 [[sync-model-selection]]。

一轮只启动一次本机 CLI，使用实际托管工作树和预先绑定的会话 UUID。原生流必须以同一会话、同一工作目录且带唯一原生 request ID 的成功终态结束。终态的 request ID 是 turn 身份。最后一个工具之后的完整原生文本通过冻结 JSON schema。只读任务使用计划模式，并成对关闭进入和退出计划模式的工具。细化与最终候选的两类新只读独审在 Native plan 固定 native-review-table-read-v4，读取 Markdown 表格时先解释表格转义及代码跨度，再比较业务单元格与实现的字面内容。其他新只读派发继续固定 native-file-read-v2。已检出的证据使用原生只读文件工具，避免通用终端和动态工具发现。任务确需读取当前树未检出的历史 Git 对象时才用精确只读 Git 命令。细化独审的节点生命周期及候选代码独审的 priorRefs 可能要求核对当前工作树未检出的历史 Git 对象，因此新独审沿原生只读计划的工具面。独审核对实际候选、相关源码和测试，测试执行由独立验证阶段承担。冷复验按原计划标记重建并核对真实提示摘要，已保存 native-file-read-v2、native-candidate-read-v3 的独审按各自原提示认证。工具权限和必审范围沿原定义。编辑任务在独立工作树中使用明确授权。模型的工作和正常 Git 提交由 [[native-worktree-runtime]] 从实际 Git 对象核验。

在原生停止和进程组结算确证后发布结果。收到绑定原请求的成功终态且 CLI 自然退出为零时，进程组结算与读取 stdout 至 EOF 共用一次独立有界的观察窗口，轮询不延长该窗口。若后代仍占用 stdout，允许沿原进程身份与 receipt 停止已登记后代。收到绑定的成功终态后，在当前退出窗口继续复查进程归属，先给 CLI 五秒完成自己的关闭流程。原 CLI 届时仍在运行才停止已登记且身份仍匹配的后代，包括终态后才启动的后代。同一启动身份至多成功发送一次信号，CLI 自然退出立即结束此等待；本步骤不向 CLI 本身发送信号，接受结果仍须其自然退出为零。只有流实际到达 EOF 且终态后没有其他事件才接受输出。已绑定成功终态但原 CLI 超过退出观察窗口时，结果失败。用单独的有界清理窗口精确停止原进程及其已归属后代，同时确认原 stdout 到达 EOF。停止与 EOF 均确证即返回原退出失败；任一未证实则继续占用容量并保留待恢复。清理期间的退出、EOF 或输出不取得结果发布资格。取消或超时仍阻止结果发布。格式失败可保存绑定同一请求的未批准输出及真实停止后的 Git 草稿供返修。冷读取复验原件，未知启动、未知终态和未知进程组保持待结算，正式停止和回收共用现有控制路径。

新 P0 分析及独审编辑草稿时，Native plan 冻结 native-behavior-evidence-v5。业务前后状态引用任务指定的冻结源码、历史角色及真实路径、符号和断言。分析、独审和续修各自的临时 HEAD、祖先关系及草稿提交用于核对工作树协议；不能代替业务证据。续修将草稿中的临时身份叙述改为冻结业务证据。独审仍逐项检查真实冻结对象，发现错误源码、冻结对象或临时 HEAD 主张时要求修复。旧编辑计划缺该标记时按原提示冷验。独审范围、权限、原 Git 观察及验收沿原规则。

周期观察遇到暂态 pending 时，在 [[native-worktree-runtime]] 的固定观察窗口内继续核验原会话。窗口耗尽或发生非暂态故障时停止原轮。新鲜停止证明成立时登记为失败，停止仍未知时保持待结算。原终态与正式取消优先，恢复不重派任务。

Grok 在成功终态后逾期退出并经清理取得正式失败时，原未公开的 thread/turn 保持缺席。冷态读取未批准的 P0 分析或完整 P1 细化 Git 草稿，须额外认证 canonical 失败、原工作树、策略和提示、原生计划与 launch/receipt、精确进程已停止、末条停止观察及未形成成功结算。原任务继续失败，不从清理重建 Native 输出。
