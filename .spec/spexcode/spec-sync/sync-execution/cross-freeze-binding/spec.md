# 跨冻结分区证据的来源绑定

## raw source

同一次新 initial 的重跑和冷恢复应沿首次固定的旧来源。后续出现的新材料、原工作区前进或并发执行不得改变该次选择。

## expanded spec

首次选择只接收独立提交型 initial。使用独立 Git 查询，确认实际 canonical 工作树、主分支、HEAD 和 tree 与当前冻结一致，index、工作区和 Git 可见未跟踪项干净。存在隐藏工作区变化的 index 标记、Git 读取异常或输入已移动时，按无来源继续当前正常同步。

通过 [[cross-freeze-source]] 读取当时已结算的原操作。用版本化绑定记录当前操作、输入、政策、指定来源、原操作、可用尝试顺序和 [[cross-freeze-provenance]] 完整证据的内容地址及摘要。没有合格来源同样固定为明确决定。协调器使用操作级持久记录原子保留首次决定；并发调用复验实际胜出的固定值。

恢复先读取绑定，重新核对当前冻结身份、原操作、原尝试及完整 Git 证据。恢复沿不可变对象，允许实际 HEAD 已在同一主分支向前。绑定缺损、原来源不再合格或证据摘要不符时拒绝复用并保留固定记录及拒绝原因。当前分区的独审和交付继续遵循 [[sync-coordinator]]。
