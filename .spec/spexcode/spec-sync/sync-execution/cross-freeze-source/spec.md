# 跨冻结分区证据的原操作选择

## raw source

新 initial 只从当前提交之前正式接入的已结算操作承接旧材料。选择和复验只读旧记录，当前分区仍由本次独审决定能否使用。

## expanded spec

当前操作须是独立的 canonical 提交快照 initial，无 retryOf 或受控正文差量。正式接入时检查主分支及工作区干净，冷验只读原接入固定快照。原操作同属 initial 和同一完整工作树身份，产生于本操作之前。两端原接入收据、冻结政策、原始需求与 [[cross-freeze-provenance]] 的真实 Git 绑定均须可核验。旧工作区冻结只有在正文、index tree 和真实提交 tree 相同时才可提供材料。

来源须处于失败、预算耗尽、取消、被替代或已完成交付写入的结算状态。暂停与在途阶段缺少资格。所有旧尝试须正式结束，原生资源均已 removed，交付日志均已结算，且无有效租约。返回仍可沿正式快照及检查点追溯的原尝试。旧发布、待采纳交付及 Git 引用均保留原身份。

未指定来源时从当前操作之前按正式接入顺序选最近合格项。显式来源和冷验只核已绑定项；旧尝试集合或完整差量摘要发生变化时不再给出该来源。来源选择仅提供原记录和双冻结证据；旧阶段结论须沿原件认证，当前分区的独审、验证和采纳遵循 [[sync-coordinator]]。
