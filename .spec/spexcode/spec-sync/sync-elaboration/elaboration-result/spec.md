# 细化输入快照与可追溯结果

## raw source

未知业务政策只阻塞依赖分支；失败、预算耗尽和待输入结果应保留可检查产物，不能显示已同步。

## expanded spec

输入快照拥有用户原意节点和原文、允许变更的节点与路径、源正文及摘要、既有只读契约、有来源的事实和可选实际代码/测试字节。新增子节点原意或上层引用正文必须由冻结输入提供；模型不能自行扩大写范围。`authorizedChanges` 是调用者已确认原意或裁决产生的具体退役/验证政策变更，不接受模型自产批准；历史 `retiredIds` 由协调器登记，新候选不得复用。每次请求携带稳定请求键及独立输入摘要；修复调用次数有明确上限。

结果返回候选正文及内容摘要、解析图与覆盖投影、具体 GAP、受阻依赖 ID 和可独立推进 ID、实际退役 ID、结构与独立审查结论。可推进/退役结论仅在当前结构和独立审查通过后输出。每轮保留生成输出、审查输出、失败发现和 session/thread/turn/result 摘要，不能只保留最后“成功”声明。调用期间外部继续编辑不改变冻结输入。

细化状态遵循上层 [[sync-elaboration]]；实现缺口、实际执行 `not_run` 和 `implementationReady: false` 始终明确。P2 及验证服务必须另外完成代码、测试、当前版本证据和允许范围的实际落盘，才能形成 [[sync-verification]] 定义的同步结论。
